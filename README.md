# SparkSpirit Shop

A premium fashion e-commerce site designed for a high-end, minimalist aesthetic.

## Tech Stack

- **Backend**: Node.js, Express, Prisma, SQLite3
- **Frontend**: React (Planned)
- **Deployment**: Render (Backend), Vercel (Frontend)

## Project Goals

- Minimalist, high-fashion design
- Full CRUD for products and categories
- Smooth user flow: Home -> Category -> Product -> Cart

## Development Instructions

1.  Use SQLITE3 for database storage implementation
2.  Use Prisma for ORM
3.  Implement at least one full CRUD RESTful API
4.  Deploy it on Render for backend and vercel for frontend
5.  Resolve CORS issue if needed after deployment
